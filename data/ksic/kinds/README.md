# 세부 업종 규칙 (낱말 → 세부 업종 → 초안 숫자)

사업을 한 문장으로 적으면 AI 없이 초안을 채우는 표다. `NN.tsv`(사람·에이전트가 쓰는 원본) → `node scripts/kind-rules.mjs build` → `../kind-rules.json`(앱이 읽는 파일).
숫자는 통계가 아니라 **출발용 짐작값**이다. 화면에 'AI 초안'으로 표시되고 사용자가 고친다.

## 한 묶음 쓰는 법
1. `todo/NN.tsv`를 읽는다 — 한 줄이 표준산업분류 세세분류 하나(`code name path sector revenue`).
2. 분류마다 **창업자가 실제로 입에 올리는 세부 업종**을 줄로 적는다. 손님을 직접 만나는 분류(소매·음식·교육·개인 서비스·여가·숙박)는 5~12줄, 그 밖(제조·도매·건설·전문 서비스)은 1~4줄.
   - 예: `56111 한식 일반 음식점업` → 국밥집, 백반집, 김치찌개집, 칼국수집, 보쌈·족발집, 한정식집 …
   - 1~10명이 5억원 안쪽으로는 시작할 수 없는 분류는 줄 대신 `# skip 코드 이유` 한 줄을 적는다.
3. `data/ksic/kinds/NN.tsv`에 저장하고 `node scripts/kind-rules.mjs check data/ksic/kinds/NN.tsv`가 통과할 때까지 고친다.

## 줄 형식 (탭으로 나눈 10칸, 머리줄 없음)
`code	offer	words	customer	problem	channel	price	unitCost	cost	capacity`

| 칸 | 내용 | 규칙 |
| --- | --- | --- |
| code | 세세분류 5자리 | 그 묶음 todo에 있는 코드 |
| offer | 파는 것 | 2~30자. 예: `돼지국밥·순대국 한 그릇` |
| words | 이 업종을 가리키는 낱말, 쉼표로 | 3~15개(6개 이상 권장). 한글·영소문자·숫자만, **띄어쓰기 없이** 2~12자. 창업자가 문장에 쓸 말(가게 이름·대표 상품·줄임말·영어 표기). 예: `국밥집,돼지국밥,순대국,순댓국,해장국집` |
| customer | 주요 고객 | 4~40자. 누구인지 구체적으로 |
| problem | 그 고객의 불편 | 4~50자. `~이 없음`, `~하기 어려움` 꼴 |
| channel | 손님을 만나는 곳 하나 | 2~30자. 예: `매장 방문`, `네이버 검색·플레이스`, `배달앱`, `스마트스토어`, `인스타그램`, `숨고·크몽`, `지인 소개·기존 거래처`, `직접 영업·견적 요청` |
| price | 값(원, 정수) | 아래 '숫자 기준' |
| unitCost | 1건에 드는 재료·수수료(원, 정수) | 0 이상, price보다 작게 |
| cost | 매달 나가는 고정비(원, 정수) | 10만원 이상. 임대료·공과금·구독료 등 |
| capacity | 감당하는 양 | `하루 40그릇` · `일주일 10건` · `한 달 20명` 꼴(기간 + 띄어쓰기 + 숫자 + 단위) |

## 낱말 고르는 기준
- 그 업종만 가리키는 말만. `가게`·`판매`·`서비스`·`온라인`처럼 어디에나 붙는 말, 다른 흔한 말 속에 들어가는 말(`기타`, `배달`)은 넣지 않는다.
- 3자 이상 낱말은 문장 어디에 들어 있어도 맞는 것으로 본다(띄어쓰기를 지운 문장에서). 2자 낱말은 그 낱말로 시작하는 어절일 때만 맞는다 — 뚜렷한 명사(`꽃집`, `과외`)만 넣는다.
- 한 묶음 안에서 같은 낱말을 두 줄에 쓰지 않는다. 더 좁은 업종 줄에 준다.

## 숫자 기준
대표자 혼자 또는 2~3명이 **자리 잡은 뒤 한 달**을 기준으로, 한국 시세에 가깝게.
- `revenue`가 `per_unit`·`mixed`·`rental`: price = 대표 상품·서비스 **1건** 값, capacity = 하루/일주일 건수.
- `project`: price = 프로젝트 1건 값, capacity = `한 달 N건`.
- `subscription`: price = **월** 회비·구독료(1명), capacity = `한 달 N명`(유지하는 회원 수).
- `commission`: price = 거래 1건에서 **받는 수수료**(원), capacity = `한 달 N건`.
- `per_hour`: price = 1시간 값, capacity = `일주일 N시간`.
- 반드시 흑자: 한 달 수량 × (price − unitCost) > cost. 한 달 수량 = 하루×26, 일주일×4.3, 한 달×1.
- 과장 금지: 한 달 남는 돈(수량 × 마진 − cost)은 2,000만원 이하, 한 달 매출은 1억원 이하.
