# 사업 기획 대화 UX 개편

## 범위

2026-09-07, `/plan/chat`와 사업 기획 메시지 처리만 변경한다. 홈페이지, 판매 가격, 결제 권한, 고객 랜딩페이지, PDF/PPT 템플릿은 변경하지 않는다.

## 구현 상태

- [x] 첫 질문, 짧은 세 가지 진입 선택지, 가까운 입력창. 기존 문서 첨부 유지.
- [x] PC 대화/사업안 나란히 배치, 모바일 대화/내 사업안 전환. 두 화면을 언마운트하지 않아 읽던 위치 유지.
- [x] 사업 소개 / 상품과 고객 / 비용과 운영 / 시작 방법으로 결과 분리. 제안과 사용자 제공 내용 구분.
- [x] 긴 설계는 저장하되 채팅에는 저장된 필드에 근거한 짧은 요약 표시. 추가 요약 모델 호출 없음. 과거 상세 답변은 펼쳐 보기로 보존.
- [x] 수정 요청을 대화 입력창으로 연결. 변경된 필드 잠시 강조. 문서 수정 필요 상태와 수동 편집 보존 안내.
- [x] 입력 즉시 전송 대기 표시. 실패 시 입력 유지, 같은 탭의 미전송 텍스트는 sessionStorage로 복원.
- [x] 과거 대화 읽는 중 자동 스크롤 중단, 새 답변 버튼 제공. 한국어 조합 중 전송 방지. 모바일 Enter는 줄바꿈.
- [x] 로그인 및 무료 제작 범위를 제작 전에 안내. 결과 준비 후 주 동작을 계획서 보기로 전환.
- [x] 저장된 요청, 작업 ID, 처리 단계, 재접속 조회, 실패 재시도 구현. 기존 PlanSectionsWorkflow에 구분된 coach 작업을 추가.
- [x] 중복 작업 선점 및 구버전 저장 차단. 서버 작업 접수 불확실 시 같은 runId를 조회하고 별도 작업을 자동 재생성하지 않음.
- [x] 일반 문서 자동 저장에서 서버 대화·작업·생성 메타데이터 보호. 오래된 화면이 최신 작업 상태를 덮지 않도록 작업 갱신 시각도 비교.
- [x] 실제 서버 접수가 확인된 작업에만 화면 종료 안내. 로컬 동기 경로는 화면 유지 안내.
- [ ] 새 coach Workflow를 실제 Cloudflare에서 실행하고 화면 종료 후 완료까지 확인.
- [ ] 새 화면에서 실제 계정 로그인 복귀, 무료/유료 문서 생성 및 다운로드까지 검증.
- [ ] 아이디어 미정 / 신규 / 운영 개선 세 유형을 새 화면과 실제 모델로 다시 검증.
- [ ] 초보 사용자 관찰 테스트. 제작 및 수정 버튼을 설명 없이 찾는지 확인.

## 서버 작업 처리

1. 소유권, 버전, 이용량, 기존 실행 여부 확인.
2. `__coach_job`에 원문과 요청 ID를 저장하고 일일 대화 이용량을 예약.
3. Supabase와 Workflow가 있으면 작업을 접수하고 202 반환. 접수가 확인되지 않으면 확인 중 상태로 유지.
4. 동일 작업의 실행 권한을 저장소에서 한 번 선점. 이해 / 설계 / 저장 단계만 실제 처리 시점에 기록.
5. 결과 저장 시 요청 토큰과 기존 대화 버전 재검사. 실패 시 마지막 정상 사업안 및 실패 원문 유지.
6. 실패 요청은 같은 원문으로 최대 두 번 추가 재시도. 같은 저장 요청의 재시도는 새 대화 횟수로 계산하지 않음. 실제 API 호출은 추가로 발생할 수 있음.

다른 사업에서 동시 요청하는 계정 단위 이용량 예약은 기존 consult 저장 방식을 유지한다. 계정 전체의 엄밀한 원자적 쿼터 예약은 별도 개선 대상이다. 프로세스 메모리 모드는 영구 저장으로 안내하지 않는다. 브라우저의 게스트 쿠키 삭제나 다른 기기에서도 동일한 대화를 복원한다고 보장하지 않는다.

- 위 브라우저 테스트는 로컬 API 응답을 대체한 UI 검증이다. 실제 Cloudflare나 AI 응답 품질 테스트가 아니다.
- `scripts/business-coach-job.test.ts`: 저장 후 생성, 중복 선점 차단, 완료 재호출, 소유권, 구작업 저장 차단, 실패 원문 및 정상 버전 유지. AI/저장소는 테스트 대역.
- 기존 business-design, business-coach, business-coach-concurrency, business-coach-attachment, plan-section-service 회귀 검사 통과.
- TypeScript 검사 및 격리된 복사본의 Next 배포용 빌드 통과. 개발 서버 8083은 유지.
- 스크린샷: `artifacts/business-coach-ux/`. 운영 환경에 배포하지 않았다.

## 배포 시 주의

프런트엔드만 올리지 말고 API·내부 계획 서비스·PlanSectionsWorkflow를 함께 배포해야 한다. 기존 워크플로 바인딩 이름과 섹션 생성 payload는 유지한다. 버전 미리보기의 self-reference가 이전 운영 Worker를 가리키면 새 coach 작업을 검증할 수 없으므로 별도 검증 환경의 호출 대상을 먼저 확인해야 한다.

## 2026-09-08 입력 경험 보완

- 첫 화면부터 도우미의 인사와 답변 선택지를 실제 대화 영역에 표시. 인사는 답변 후에도 보존하고 사용자 메시지는 오른쪽 파란 말풍선으로 표시.
- 입력창은 처음부터 하단에 고정. 첨부, 자동 높이 조절 입력창, 전송을 한 줄에 배치하고 키보드가 열리면 대화 영역만 줄임. 말풍선 등장, 답변 선택지 눌림, 작성 중 점 애니메이션 적용.

### 앱형 화면 재구성
- 모바일은 뒤로가기, 대화 제목, 더보기 메뉴를 가진 전용 헤더 사용. PC는 새 대화와 내 사업을 왼쪽 작업 메뉴로 분리.
- 첫 메시지는 큰 글자와 짧은 문장으로 표시하고 답변 선택은 60px 이상의 전체 너비 행으로 제공. 진행 후에는 일반 대화 크기로 전환.
- AI 파트너임을 표시하고 첨부·입력·전송은 하단에 유지. 더보기 메뉴는 외부 클릭과 Escape로 닫을 수 있음.
- 변경 범위는 `/plan/chat`의 화면 구성. 사업안 생성, 결제, 서버 저장 로직은 변경하지 않음.
- 실제 후속 답변, 작성 중 상태, 사업안 결과 연결, 수정 선택지에도 동일한 프로필·글자·버튼 스타일 적용. 후속 선택지는 대화 영역으로 이동해 하단 입력 공간을 확보.
- 가장 최근의 긴 답변은 자동으로 접지 않음. 이전 답변은 원문을 보존한 채 펼쳐볼 수 있으며, 사업안 패널도 같은 스타일로 연결.
- 시스템의 동작 줄이기 설정 존중. 자동 스크롤의 긴 이동 애니메이션은 제거하여 사용자가 읽던 위치와 충돌하지 않도록 수정. 메시지 자체의 등장 효과는 유지.
- 사업 생성·저장·결제 로직은 이번 보완에서 변경하지 않음.
