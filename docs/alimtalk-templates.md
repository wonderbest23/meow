# 카카오 알림톡 템플릿 (알리고에 등록)

알림톡은 문자와 같은 **알리고 계정·같은 중계 서버**로 보냅니다(사이트 → 중계 서버(고정 IP) → 알리고 카카오 API).
템플릿이 승인된 알림만 알림톡으로 가고, 알림톡이 실패하면 알리고가 같은 내용을 **문자로 대신** 보냅니다(failover).
승인 전이거나 템플릿 코드를 넣지 않은 알림은 지금처럼 문자로 갑니다.

> 아래 글은 중계 프로그램(`ops/owner-sms/relay.py`의 `ALIMTALK_TEMPLATES`)과 **한 글자도 달라선 안 됩니다.**
> 카카오는 등록한 글과 보낸 글이 다르면 거절합니다. `#{…}` 자리만 값으로 바뀝니다.

## 준비 (한 번)
1. 카카오톡 채널 만들기 → 비즈니스 채널 인증(사업자등록증)
2. 알리고 관리자(smartsms.aligo.in) → 카카오톡 → **발신프로필 등록** → 발신 프로필 키(senderkey) 확인
3. 알리고 → 카카오톡 → **템플릿 등록**: 아래 7개를 그대로 등록(메시지 유형: 기본형, 버튼은 '웹링크')
4. 승인되면 템플릿 코드(예: `TA_1234`)를 적어 두기
5. 중계 서버에서 `relay.py`·`upgrade_v5.py` 를 같은 폴더에 올리고 `sudo python3 upgrade_v5.py`
   → 발신 프로필 키와 승인된 템플릿 코드를 물어봅니다(승인 안 된 것은 빈칸 = 문자로). 나중에 다시 실행해 채워도 됩니다.

사이트(Cloudflare) 쪽 설정은 바꿀 것이 없습니다. 운영자 결제 알림은 지금처럼 문자입니다.

## 템플릿 (메시지 유형: 기본형 · 카테고리: 알림/안내)

### payment-receipt — 결제한 분께
```
[오늘창업] 결제가 완료됐어요.

상품: #{상품}
주문번호: #{주문번호}

결제 내역과 영수증은 오늘창업 마이페이지에서 볼 수 있어요.
```
버튼(웹링크): `마이페이지` → https://oneulstart.com/plan/me

### homepage-lead-contact — 사장님께(새 문의, 연락처 포함)
```
[오늘창업] 홈페이지에 새 문의가 들어왔어요.

이름: #{이름}
연락처: #{연락처}

빠르게 연락드리면 상담으로 이어질 가능성이 높아요.
```
버튼(웹링크): `문의 확인` → https://oneulstart.com/plan/homepage

### homepage-lead — 사장님께(새 문의, 연락처 없이 — 예전 방식)
```
[오늘창업] 홈페이지에 새 문의가 들어왔어요. 오늘창업에서 내용을 확인해 주세요.
```
버튼(웹링크): `문의 확인` → https://oneulstart.com/plan/homepage

### lead-received — 문의한 손님께
```
[#{가게}] 문의가 접수됐어요.

남겨 주신 연락처로 곧 연락드릴게요. 감사합니다.
```

### domain-connect-started — 사장님께
```
[오늘창업] 도메인 #{도메인} 연결을 시작했어요.

연결이 끝나면 이 주소로 홈페이지가 열려요. 보통 수 분~몇 시간 걸려요.
```

### tax-deadline — 사장님께
```
[오늘창업] #{세금} 신고 마감이 #{남은날}일 남았어요.

마감일: #{마감일}

홈택스에서 신고·납부할 수 있어요. 늦으면 가산세가 붙어요.
```
버튼(웹링크): `홈택스` → https://hometax.go.kr

### weekly-report — 사장님께(주간 리포트)
```
[오늘창업] 지난주 홈페이지 리포트

문의: #{문의}건 (전주 #{전주문의}건)
방문: #{방문}회
```
버튼(웹링크): `자세히 보기` → https://oneulstart.com/plan/homepage
