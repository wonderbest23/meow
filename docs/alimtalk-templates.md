# 카카오 알림톡 템플릿 (솔라피 콘솔에 등록)

알림톡은 카카오가 검수한 글만 보낼 수 있습니다. 아래 글을 **그대로** 솔라피 콘솔 → 카카오 알림톡 → 템플릿 관리에 등록하고,
승인되면 템플릿 ID 를 `SOLAPI_ALIMTALK_TEMPLATES` 에 넣습니다. `#{…}` 이름을 바꾸면 값이 안 들어갑니다(`lib/notify/alimtalk.ts`).

## 준비 (한 번)
1. 카카오톡 채널 만들기 → 비즈니스 채널 인증(사업자등록증 필요)
2. 솔라피 가입 → 카카오 채널 연동 → 채널 ID(`KA01PF…`)를 `SOLAPI_PFID` 에
3. 솔라피 API Key 발급 → `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`
4. (선택) 솔라피에 발신번호 등록 → `SOLAPI_SENDER` — 알림톡이 실패하면 솔라피가 같은 내용을 문자로 대신 보냄
5. 아래 템플릿 등록·승인 후 Cloudflare 환경변수에:
   `SOLAPI_ALIMTALK_TEMPLATES={"payment-receipt":"KA01TP…","homepage-lead-contact":"KA01TP…", …}`

템플릿이 없는 알림은 지금처럼 알리고 문자로 갑니다. 운영자 결제 알림은 문자 그대로입니다.
알림톡은 `OWNER_SMS_MODE=live` 일 때만 보냅니다(시험 모드에서는 보내지 않음).

## 템플릿 (메시지 유형: 기본형 · 카테고리: 알림/안내)

### payment-receipt — 결제한 분께
```
[오늘창업] 결제가 완료됐어요.

상품: #{상품}
주문번호: #{주문번호}

결제 내역과 영수증은 오늘창업 마이페이지에서 볼 수 있어요.
```
버튼(웹링크): `마이페이지` → https://oneulstart.com/plan/me

### homepage-lead-contact — 사장님께(새 문의, 연락처 포함)
```
[오늘창업] 홈페이지에 새 문의가 들어왔어요.

이름: #{이름}
연락처: #{연락처}

빠르게 연락드리면 상담으로 이어질 가능성이 높아요.
```
버튼(웹링크): `문의 확인` → https://oneulstart.com/plan/homepage

### homepage-lead — 사장님께(새 문의, 연락처 없이 — 예전 방식)
```
[오늘창업] 홈페이지에 새 문의가 들어왔어요. 오늘창업에서 내용을 확인해 주세요.
```
버튼(웹링크): `문의 확인` → https://oneulstart.com/plan/homepage

### lead-received — 문의한 손님께
```
[#{가게}] 문의가 접수됐어요.

남겨 주신 연락처로 곧 연락드릴게요. 감사합니다.
```

### domain-connect-started — 사장님께
```
[오늘창업] 도메인 #{도메인} 연결을 시작했어요.

연결이 끝나면 이 주소로 홈페이지가 열려요. 보통 수 분~몇 시간 걸려요.
```

### tax-deadline — 사장님께
```
[오늘창업] #{세금} 신고 마감이 #{남은날}일 남았어요.

마감일: #{마감일}

홈택스에서 신고·납부할 수 있어요. 늦으면 가산세가 붙어요.
```
버튼(웹링크): `홈택스` → https://hometax.go.kr

### weekly-report — 사장님께(주간 리포트)
```
[오늘창업] 지난주 홈페이지 리포트

문의: #{문의}건 (전주 #{전주문의}건)
방문: #{방문}회
```
버튼(웹링크): `자세히 보기` → https://oneulstart.com/plan/homepage
