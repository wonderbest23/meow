# 실제 창업자 시험 계획 (2026-10-14)

시뮬레이션과 실제 API 시험으로는 '계획서가 맞게 쓰였는가'까지만 볼 수 있다. 이 시험은 그다음 질문을 본다: **진짜 창업 준비 중인 사람이 이 계획서를 받고 실제로 움직이는가, 돈을 낼 만하다고 느끼는가.**

## 1. 누구를 (3~5명)

- 지금 창업을 준비 중이거나 막 시작한 사람(아이디어만 있는 사람보다 3개월 안에 시작할 사람).
- 업종을 섞는다. 지금까지 시험한 유형 가운데 최소 세 가지:
  - 매장·공간형(네일·카페·연습실)
  - 온라인 판매형(스마트스토어)
  - 방문·교육형(과외·출장 서비스)
  - 기업 대상 서비스(SNS 대행 등)
- 아는 사람이 아니면 더 좋다. 아는 사람은 좋은 말만 하기 쉽다.
- 찾는 곳(예): 지인 소개, 지역 창업 커뮤니티, 소상공인 교육 수강생.

## 2. 어떻게 (1명당 약 1시간 30분)

1. **상담(약 20분)**: 본인이 직접 오늘창업 상담 화면에서 질문에 답한다. 대표는 옆(또는 화상)에서 보기만 하고 돕지 않는다. 막히는 곳은 적어 둔다.
2. **계획서 받기(약 7분)**: 계획서가 만들어지는 동안 기다리는 화면을 어떻게 느끼는지 본다.
3. **혼자 읽기(약 30분)**: 처음부터 끝까지 읽게 한다. 어디서 멈추는지, 어디를 건너뛰는지 본다.
4. **질문(약 20분)**: 아래 3장의 질문을 한다.
5. **2주 뒤 연락(10분)**: '이번 주 할 일'과 12주 표의 1~2주차를 실제로 했는지 묻는다. **이게 가장 중요한 결과다.**

## 3. 끝나고 물을 질문

1. 이 계획서에서 처음 알게 된 것이 있었나요? 있으면 무엇인가요?
2. 틀렸거나 내 사업과 안 맞는 곳이 있었나요? (장 이름과 문장)
3. 이해가 안 된 숫자나 말이 있었나요?
4. 내일 무엇부터 하시겠어요? (계획서의 '이번 주 할 일'과 같은지 본다)
5. 이 계획서에 얼마까지 낼 수 있나요? 왜 그 금액인가요?
6. 다른 사람에게 권하겠어요? 누구에게요?

## 4. 무엇을 보면 통과인가

| 기준 | 통과 |
|---|---|
| 치명적 오류(틀린 인허가 순서, 틀린 계산) | 5명 모두 0건 |
| 이해 못 한 숫자·말 | 1명당 3개 이하 |
| '내일 할 일'이 계획서와 같음 | 4명 이상 |
| 2주 뒤 1~2주차 할 일을 실제로 함 | 3명 이상 |
| 낼 수 있는 금액이 정한 가격 이상 | 3명 이상 |

통과하지 못한 항목은 업종과 장 이름을 붙여 기록하고, 여러 사람에게 공통으로 나온 것만 고친다(한 사람만의 의견은 기록만).

## 5. 비용

- 1명당 계획서 1건의 AI 원가는 약 5,000~6,000원이다(2026-10-13 실제 API 8건 기준).
- API는 프로모션 크레딧만 쓴다. 단, 월 지출 한도(US$100)에 프로모션 사용분도 잡힌다. 이번 달은 거의 다 썼으므로 11월 1일 뒤에 시작한다.

## 6. 대표가 정할 것

1. ~~시험하는 분이 돈을 내는가~~ → **정가를 받는다(2026-10-14 대표 결정).** 가장 정직한 반응을 보기 위해서다. 결제 과정도 함께 시험된다.
2. **어디로 들어오게 할지**: 운영 주소인지, 프리런치 주소인지.
3. **보상**: 시간을 내준 분께 드릴 사례(예: 계획서 무료 + 상품권).
