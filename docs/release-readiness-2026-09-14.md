## 재실행과 증거

`scripts/local-release-validation.mts`는 위 로컬 검사를 순서대로 실행한다. 운영 환경파일을 받지 않고, 자식 프로세스에 AI/PG 키를 전달하지 않는다. 현재 앱 소스와 로컬 서버 복사본의 내용이 다르면 실행을 중단한다.

- 각 검사마다 결과를 저장한다. 실패·시간 초과를 성공으로 계산하지 않는다.
- 홈페이지 데이터 검증 실패 시 그 결과에 의존하는 브라우저 검사는 건너뛴다.
- 테스트 중 앱 소스 또는 예산 장부가 바뀌면 전체 로컬 통과를 취소한다.
- 로컬 검사 성공이어도 `releaseReady`는 false로 남긴다. 외부 출시 검증 승인을 자동 생성하지 않는다.

```sh
RUNTIME_NODE_MODULES=/Users/juhong/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules node --import tsx scripts/local-release-validation.mts
```

실행 전 격리 서버의 소스 복사본을 최신화해야 한다. 운영 `.env.local`을 불러오거나 로컬 테스트의 localhost 제한을 해제해서 외부에 실행하지 않는다.

- 종합 보고서: `artifacts/local-release-validation/2026-09-14T11-58-53-547Z/report.json`
- 계정 통합: `artifacts/local-account-integration/report.json`
- 홈페이지: `artifacts/local-homepage-lifecycle/report.json`, `browser-report.json`
- 계획서/PPT: `artifacts/document-refresh-20260914/`, `/private/tmp/oneul-document-refresh-20260914/`
- 격리 빌드: `/private/tmp/oneul-staging-build-V5nxxG/staging-build-report.json`

로컬 테스트 계정 정보는 결과 문서에 포함하지 않는다. `artifacts/`는 Git에서 제외된 상태를 유지한다.

## 외부 검증을 재개하는 조건

1. **AI 전송 승인**: 화면에서 확인하고 동의한 사업 조건·선택 문서 본문·관련 슬라이드 문안을 OpenAI에 전송하도록 연결하는 범위를 승인한다. 공개 생성 경로는 현재 503으로 닫혀 있다.
2. **비용 승인**: 기존 누적 장부를 유지한 채 추가 검증 한도를 확정한다. 이번에는 추가 5달러 승인을 요청했으며, 답변 전 유료 호출은 실행하지 않는다.
3. **DB 구조 일치**: 9월 15일 `newapp`에 0027~0030을 반영했고 비회원 자료 이전·홈페이지 공개/복원을 실제 DB와 임시 로컬 앱에서 검증했다. 원격 앱의 계정 연결 스위치와 소유권 키 일치는 별도 배포 단계에서 확인한다. `testapp` 정지나 유료 전환은 필요하지 않다.
4. **Google/PG 테스트 설정**: 운영과 분리된 인증 origin과 테스트 가맹점/콜백을 준비한 뒤 실제 테스트 여정을 실행한다. 비밀값은 채팅에 전달하지 않는다.

이후 순서는 전용 DB/접근 보호 → 승인된 AI 생성기와 백그라운드 작업 연결 → 실제 생성·재접속 복구 → Google/PG 검증 → 알림·복구·비용 정책 확인 → 제한 출시 승인이다. 외부 프로젝트나 운영 배포는 로컬 성공만으로 개방하지 않는다.

## 범위 밖의 잔여 제품 기능

다른 업종에 대한 고품질 제안서 표본 검수, 6장 초과 영향 변경의 전체 재생성 병합, 이미지 교체/크롭과 복잡한 표·차트 편집, 전문 서비스의 견적·담당자·납품 상태 연결은 별도 제품 작업으로 남아 있다. 현재 구현을 이 기능까지 포함한 완성형 플랫폼으로 안내하면 안 된다.
