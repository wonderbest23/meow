# 공통 사업 조건과 제안서 연결 검증

## 이번 구현

- 제안서 편집기에서 상품·제공 범위, 고객, 판매가, 변동비, 월 고정비, 월 판매 건수를 공통 사업 정보에 저장한다.
- 기존 대화 화면과 같은 `coach` 데이터와 수정 이력을 사용하며 별도 사업 정보를 만들지 않는다.
- 입력한 조건의 월 예상 매출·변동비·영업손익을 기존 계산 모듈로 비교한다. 미입력 비용을 0원으로 보지 않으며 실제 실적으로 표시하지 않는다.
- 사업 조건, 계획서 항목, 제안서의 반영 상태를 분리해서 보여준다. 공통 조건 저장만으로 기존 본문과 PPT를 덮어쓰지 않는다.
- 사업 조건 PATCH에 요청 서명과 저장 영수증을 추가했다. 같은 요청 재전송은 한 번만 반영하며 같은 ID의 다른 내용과 오래된 사업 버전은 거절한다. 일반 자동저장은 이 기록을 바꾸지 못한다.
- 문서 화면에서 현재 사업 조건을 확인하고 항목별로 검토 완료를 기록할 수 있다. 본문을 수정하는 동작과 최신 조건으로 검토 완료하는 동작을 구분한다.
- 검토 완료는 사업 원문 버전과 본문 저장 시각을 모두 검사한다. 검토 중 사업이 바뀌면 승인되지 않는다. 예전 본문 복원 시 다시 검토해야 하며 기존 본문 복원 기록은 보존한다.
- 최신 사업 조건으로 검토되지 않은 수동 수정·잠금 문서를 PPT 최신 원문으로 사용하는 경로를 차단했다.
- AI 전송 미리보기에는 사업명·설명, 필요한 원문과 변경 전후 내용, 관련 기본 슬라이드 문안을 표시한다. 이미지·배치·사용자의 슬라이드 수동 문안은 제외한다. 대상과 자료 해시에 동의를 연결하고 체크박스는 기본 해제한다.
- 합성 테스트용 부분 재작성 서비스는 요청 예약과 실행 선점을 분리했다. 동일 작업의 중복 실행은 한 번만 처리한다. 실제 외부 워크플로 연결은 하지 않았다.

## 검증 범위

검증 환경은 `http://127.0.0.1:8094`, 별도 로컬 Supabase는 `http://127.0.0.1:55431`이다. 운영 DB, 운영 배포, 실제 결제를 사용하지 않았다.

1. 가상 운영 사업의 가격을 150만원에서 180만원으로 변경했다. 월 판매 2건, 건당 변동비 30만원, 월 고정비 50만원 조건에서 예상 영업손익이 190만원에서 250만원으로 바뀌었다.
2. 저장 응답을 의도적으로 끊고 같은 요청으로 재확인했다. 사업 수정 버전은 한 번만 증가했다.
3. 기존 제안서의 150만원은 승인 전까지 그대로 보존됐고 오래된 계획서로 변경안을 만들 수 없었다.
4. 문서 화면에서 최신 조건 표시와 체크 후 검토 완료를 확인했다. 나머지 가상 문서 항목은 실제 문서 수정·검토 API를 통해 처리했다.
5. 전송 미리보기와 체크박스는 브라우저에서 확인했다. 재작성 단계만 테스트가 모의 응답으로 대체했으며 외부 모델 호출은 없었다.
6. 3개 관련 페이지의 변경안을 승인한 뒤 재접속·로그아웃·로그인·버전 지정 PPT 다운로드를 확인했다. 내려받은 PPT 내부에 새 가격이 남았다.
7. 320·390·768·1440px에서 가로 넘침이 없음을 확인했고 모바일·데스크톱 화면을 육안 검토했다.
8. 별도 메모리 테스트는 요청 ID 재사용, 소유자 분리, 오래된 사업 버전, 검토 중 조건 변경, 예전 문서 복원, 실행 선점 중복도 검사한다.

브라우저 테스트: `scripts/local-proposal-business.test.mts`

## 아직 열지 않은 것

- 이번 문서 갱신 검증은 **명시적 수동 편집·검토**다. 공통 조건 변경 후 실제 AI가 계획서 전체를 재작성하는 과정까지 검증한 것은 아니다.
- 실제 사용자 자료의 OpenAI 전송 연결은 안전 검토에서 차단됐다. 사용자에게 사업명·변경 문서 본문·관련 슬라이드 문안의 동의 기반 전송 연결 승인을 요청했다. 공개 generate API는 503을 반환하며 런타임은 null 상태다.
- 실제 배포에서의 백그라운드 실행·재접속 복구는 미검증이다. 로컬 모의 실행 선점 검증을 외부 Workflow 검증으로 간주하지 않는다.
- 부분 재작성은 B2B 고객 제안서, 관련 페이지 최대 6장이다. 사업명 또는 넓은 범위 변경에 대한 전체 재생성은 별도 작업이다.
- 이번 유료 AI 호출과 실제 결제는 0회다. 기존 5달러 검증 예산 원장은 변경하지 않았다.
- 운영 배포, 커밋·푸시, 스테이징 Google 로그인·PG 검증은 하지 않았다.
