# AI 작업 중 '지금 하는 일' 문구 (2026-11-17)

대표 질문: "왜 우리 채팅은 AI가 무슨 생각을 하는지 안 보여 주냐" → "우리도 그렇게 하자".
Claude·ChatGPT의 생각 과정 표시, Base44가 1초마다 생각 글을 흘려보내는 방식(`docs/base44-로그인후-REA-분석-2026-10-23.md`의 `update_model`)을 참고했지만,
날것의 AI 생각 대신 **실제 진행 단계를 쉬운 말로 + 희망적인 한마디**로 보여 준다.

## 대표가 고른 것

1. **지금 있는 신호만** — 서버 저장 방식은 그대로. 장 하나 안의 '쓰는 중→검토 중→고치는 중'은 기록하지 않으므로 보여 주지 않는다(4개 장을 동시에 쓸 때 저장 충돌 위험 때문에 오픈 뒤 과제로 남김).
2. **쌓이는 목록** — 끝난 일은 ✓ 줄로 위에 쌓이고, 맨 아래에 지금 하는 일 한 줄(돌아가는 표시), 그 아래 회색 한마디.

## 원칙

- 문구는 코드가 만든다(`lib/plan-builder/work-narration.ts`). **AI 추가 호출 0회.**
- 쓰는 신호: 작업 상태(접수·실행)와 서버 기준 경과 시간, 답 수, 업종 가이드 이름(사업 방향 정리 지시문에 실제로 들어가는 그 가이드), 대표가 **직접 답한** 판매가·1건 비용·월 고정비로 코드가 계산한 남는 돈·본전, 다 쓴 장 이름과 남은 장 수.
- 쓰지 않는 것: AI가 쓴 글, 업종 기준값으로 먼저 채운 초안 숫자(basis `proposal`), 검토 전 본문, 지시문.
- 숫자는 계획서 돈 장(`section-service.intakeFinancialTable`)과 같은 갈래·같은 계산(`lib/plan-builder/work-narration-facts.ts`). 부가세를 빼는 사업은 뺀 값. 시험(`scripts/work-narration.test.ts`)이 돈 장 표에 같은 숫자가 있는지 확인한다.
- ✓는 정말 끝난 일에만: 코드 계산(요청 전에 이미 끝남), 저장된 장. AI가 하는 중인 일은 돌아가는 표시 한 줄로만.
- 희망 한마디는 고정 목록에서만 고른다. 숫자를 넣지 않고 결과를 약속하지 않는다(`NARRATION_BANNED`: 반드시·틀림없·확실히·보장·무조건·성공할·100%·대박).
- 본전 한마디는 대표가 직접 답한 양과 견줄 때만 판단한다: 닿으면 "… 안에 들어오는 숫자예요", 넘으면 그대로 말하고 "가격과 비용을 함께 다시 볼 자리예요", 견줄 양이 없으면 "이 숫자가 첫 목표가 돼요". 팔수록 손해면 손해라고만 적는다.

## 사업 방향 정리 (AI 호출 1번, 보통 30~40초)

서버 신호는 접수·실행뿐이라, 실행 중에는 이 작업이 쓰는 사실을 3초 간격으로 하나씩 쌓고 맨 아래에 AI가 하는 일을 둔다(신호가 없는 줄은 건너뜀).

```
✓ 답변 13개를 모았어요
✓ ‘반찬·도시락 가게’ 업종 기준을 찾았어요
✓ 부가세까지 빼면 한 건에 6,909원 남아요
✓ 본전은 한 달 218건
   감당할 수 있는 처리량(520건) 안에 들어오는 숫자예요
⟳ 고객·문제·돈 버는 구조를 한 장으로 묶고 있어요
   보통 30~40초 걸려요
│ 흩어진 답이 하나의 방향으로 모이고 있어요.
```

사실은 기본 질문을 다 마친 응답에 HTTP 층이 붙인다(`intake-http.ts`의 `narration`). 오래 걸리면 한마디 자리가 "평소보다 오래 걸리고 있어요 · N초. 답변은 저장돼 있어요."로 바뀐다.

## 계획서 작성 (장마다 쓰기 → 검토 → 저장, 4개씩 동시에)

`/api/plan/generation`이 쓰는 중일 때 `narration`(계산한 숫자 · 돈 장 열쇠 · 검토를 거치는지)을 함께 준다.

```
✓ ‘시장 분석’을 다 썼어요
✓ 돈 계획을 썼어요 — 본전은 한 달 218건
⟳ 지금 ‘마케팅 계획’을 쓰고 있어요
   남은 6개 항목도 이어서 써요 · 항목마다 답과 맞는지 검토한 뒤 저장해요
│ 절반을 넘었어요. 생각이 글이 되고 있어요.
```

- 0장: "N개 항목의 뼈대를 세우고 첫 항목을 쓰고 있어요"
- 쓰는 중: 문서 순서로 첫 번째 남은 장만 "지금 ‘…’을 쓰고 있어요"(그 장은 지금 묶음 안에 있다). 동시에 몇 장인지는 설계도 성공 여부에 달려 단정하지 않고 남은 수만 말한다.
- 마지막 한 장: "마지막으로 ‘요약’을 쓰고 있어요"
- ✓ 줄은 화면이 본 순서대로, 최근 3개(작업실 PC 한 줄 카드는 2개)만 — 그 앞은 "앞서 N개 항목을 썼어요".
- 멈췄으면(일부 장 실패) 예전 다시 쓰기 카드 그대로.

## 오픈 뒤 과제

- 장 안의 단계(쓰기·검토·고치기)를 보이려면 장마다 단계를 따로 저장해야 한다 — 계획 상태와 다른 가벼운 저장소(장별 키)가 필요하다.
