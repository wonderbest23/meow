## 확인하지 못한 점

계획서에는 아래 내용을 단정하지 않고 '관할 기관에 확인'으로 씁니다.

- 대출모집인: 인력·사업장 요건이 개인에게 실제로 어떻게 심사되는지
- 장비 대여: 단기 물품대여 기준이 스포츠 장비에도 그대로 적용되는지
- 금융 비교 서비스: 단순 정보 제공과 중개의 경계(금융위 유권해석 필요)
- 예비사회적기업: 업무지침 원문의 세부 요건

## 원문이 바뀐 점

- 사회적협동조합 인가 기관이 기획예산처장관으로 바뀌었습니다.
