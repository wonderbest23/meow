# 배치 7 — 보건·복지·교육·자격·금융 원문 대조 (2026-10-12)

## 요약

- 묶음 7개를 절차가 갈리는 대로 **가이드 15개**로 나눴어요. ksic 앞자리도 함께 나눴고, 원래 묶음 id는 대표 가이드에 그대로 남겼어요.
  - medical → `medical`(의원·병원·조산원) · `pharmacy`(약국·의약품 도매) · `optical-dental-lab`(안경원·치과기공소) · `vet-clinic`(동물병원) · `ambulance`(응급환자 이송업) · `massage-clinic`(안마원·안마시술소)
  - welfare-care → `welfare-care`(노인 요양·재가) · `welfare-facility`(장애인·아동 등 사회복지시설)
  - childcare → `childcare`(어린이집) · `kindergarten`(사립유치원)
  - finance-registration → `finance-registration`(대부·환전·투자자문) · `insurance-agency`(보험대리·중개·손해사정)
  - lifelong-education, professional-license, security-guard는 하나씩 유지
- 기존 가이드 확장 확인 4건: academy ← 85613·85669·85699 맞음, **rental-room ← 90212(독서실) 안 맞음**(학원법상 학원).
- verify 결정 7건: 64999 제외, 71209 professional-license, 71600·75330·87294 free-b2b-service, 85430 제외, 85614 tourism.
- 확인 못 한 점 39건(가이드별 `unverified`).
- 원문은 law.go.kr 현행본을 2026-10-12에 직접 받아 조문을 읽었어요(본문은 `LSW/lsInfoR.do`, 별표는 PDF). 별표 PDF는 가이드마다 아래에 적었어요.

## 1. medical — 병원·의원 개설

**근거 조문(직접 열어 읽음)**
- 의료법(현행 2026-10-02) <https://www.law.go.kr/법령/의료법>
  - 제33조②: 의사·치과의사·한의사·조산사 등만 개설, 면허별 개설 가능 기관 / ③ 의원·치과의원·한의원·조산원 = 시장·군수·구청장 **신고** / ④ 병원급 = 시·도 의료기관개설위원회 사전심의·본심의 → 시·도지사 **허가**, 병상 수급계획 부적합 시 불허 / ⑥ 조산원 지도의사 / ⑦ 약국 안·약국 분할·전용 통로·무허가 건축물 개설 금지 / ⑧ 1인 1개소
  - 제4조②(다른 의료인 명의 개설 금지), 제22조(진료기록부), 제27조(무면허 의료행위), 제37조(진단용 방사선 발생장치 신고·안전관리책임자·정기검사), 제45조(비급여 고지·제증명수수료 게시·초과 징수 금지), 제56조②(치료경험담·수술 장면 등 금지 광고), 제57조(신문·현수막·전단·교통수단·대통령령 인터넷매체 사전 심의)
- 의료법 시행규칙(2026-06-12) 제25조(개설신고 서류: 평면도·구조설명서·시설 준수 서류, 면허 행정정보 확인, 소방시설 적합 확인 요청, 개설신고증명서), 제26조의2(사전심의)
- 국민건강보험법(2026-10-08) 제42조(의료기관·약국 = 요양기관), 제43조(최초 청구 때 현황 신고), 제57조②(면허 대여 개설기관 부당이득 연대 징수)
- 폐기물관리법(2026-09-18) 제18조(사업장폐기물 자가 처리 또는 허가업체 위탁)
- 건축법 시행령 [별표 1](개정 2025-10-01): 제1종 근생 라목 의원·치과의원·한의원·침술원·접골원·조산원·안마원, 의료시설 = 병원급 <https://www.law.go.kr/LSW/flDownload.do?gubun=&flSeq=170002561&bylClsCd=110201>
- 부가가치세법 시행령(2026-04-01) 제35조(의료보건 용역 면세, 미용 성형·피부 시술 제외), 제109조②7호(의사업 등 간이과세 배제)
- 정부24 ‘의료기관 개설신고 또는 변경신고’ 안내(온라인 신청 = 보건의료자원 통합신고포털) 직접 열어 봄

**검색만 본 것**: 심사평가원 보건의료자원 통합신고포털 매뉴얼(검색 요약), 포털 첫 화면은 내용이 비어 열람 실패.

**엇갈리는 점**: 법은 신고 수리 기관을 ‘시장·군수·구청장’으로 쓰고, 실제 창구(보건소 등)는 지자체 위임마다 달라 가이드에는 ‘시·군·구 보건 부서’로만 적었어요. 정부24 페이지의 접수·처리기관 칸은 글자가 깨져 확인이 안 됐어요.
