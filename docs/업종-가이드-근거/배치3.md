대상 묶음: agriculture, livestock, fishery, fuel, power-generation, waste (업종 63개 + 확인 필요 2개).
결과: 가이드 9개(batch-3.json `guides`), 기존 가이드 확장 확인 2건(`extensions`), 확인 필요 업종 결정 2건(`verifyDecisions`).

## 원문을 연 방법

- 국가법령정보센터 법령 본문은 `https://www.law.go.kr/법령/<법령명>` 화면이 본문을 iframe으로 불러와 WebFetch로는 제목만 보였다. 그래서 같은 화면이 부르는 본문 주소(`/LSW/lsInfoR.do?lsiSeq=…&efYd=…`)를 직접 받아 조문을 읽었다. 출처 주소는 사람이 여는 `law.go.kr/법령/…` 형식으로 적었다.
- 별표는 같은 본문 HTML의 PDF 내려받기 주소(`/LSW/flDownload.do?flSeq=…`)를 받아 글자로 바꿔 읽었다(전기사업법 시행령 별표 1, 건축법 시행령 별표 1).
- 아래 '직접 연 원문'은 모두 2026-10-12 현재 시행본이다. 시행일(efYd)은 맨 아래 표에 적었다.
- 가이드 문장에는 숫자를 넣지 않았다. 면적·기간·용량 같은 기준값은 이 문서에만 적었다.

## 공통으로 엇갈리는 점

- **소관 부처 이름이 바뀌었다.** 2025-10-01 개정으로 전기사업법·전기안전관리법·폐기물관리법·가축분뇨법·물환경보전법·야생생물법의 장관이 '기후에너지환경부장관', 석유사업법·LPG법·석탄산업법은 '산업통상부장관'으로 바뀌었다. regimes.json의 authority('산업통상자원부')와 한국에너지공단 재생에너지 클라우드플랫폼 안내문('산업통상자원부(전기위원회)')은 옛 이름이다. 가이드는 새 이름으로 썼다.
- **법 이름이 바뀌었다.** regimes.json의 '신에너지 및 재생에너지 개발·이용·보급 촉진법'은 현재 '재생에너지 개발ㆍ이용ㆍ보급 촉진법'으로 검색된다(옛 이름 주소는 열리지 않음).
- **어업경영체 등록 창구.** regimes.json fishery authority에는 없지만, 농어업경영체법 시행규칙 제3조의2는 어업경영정보 등록을 **지방해양수산청장**에게 하도록 한다(농업은 국립농산물품질관리원, 임야는 산림청).

- 배 크기별 해기사 승무기준, 귀어 지원 창구.
