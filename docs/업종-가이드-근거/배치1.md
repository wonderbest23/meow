### 확인 못 한 것
- 즉석판매제조·가공업에도 HACCP 의무 품목 규정이 적용되는지 — 가이드는 "공장형(식품제조·가공업)으로 만들면"으로 범위를 좁혀 씀.
- 가공소금·죽염·정제소금: 소금산업진흥법 제23조②③(정제·재제조·가공소금 허가)이 2022년에 삭제된 것만 확인. 지금은 식품제조·가공업 등록만으로 되는지 미확인.
- 즉석판매 택배 기준 고시 원문(기존 2026-10-11 대조 결과 인용).
- 작업장 건축물 용도의 구체 판단, 공장 등록 면적(배치 2).
- 용기·포장 표시 세부, 재생원료 인정 절차 세부(시행규칙 제6조 제목만).

### 엇갈리는 점
- regimes.json의 food-manufacture 법령 목록에 '양곡관리법(양곡가공업)'은 맞지만, food-retail에 적힌 '양곡매매업 신고'는 현행 양곡관리법에 신고 조문이 없음(정의 제2조4호와 표시 의무 제20조의2만 있음).
- 기존 가이드 문서(2026-10-11)는 즉석판매 위생교육 시간을 6시간으로 적음 — 현행 시행규칙 제52조②3호와 같음(변동 없음).

### 엇갈리는 점
- 시행규칙 제42조①14(2026.1.2 개정)는 일반음식점도 음식판매자동차 영업을 허용하지만, 별표17 7호 허목(신고 장소 외 영업 금지)은 휴게음식점·제과점만 적고 있음.
- 생활법령 푸드트럭 페이지 하나는 대상 업종을 휴게음식점·제과점으로, 다른 페이지는 일반음식점까지로 안내함. 현행 조문은 셋 다 허용.
- 생활법령 "사유지에서는 별도 허가 없이 영업 불가"는 조례로 정한 장소면 가능할 수 있어, 가이드는 "허용 장소가 아니면 안 돼요"로 씀.
